# ADR-0018: 「On Vox:」記事は抜粋だけのものと重複を消し、残す記事は接頭辞を外してJSTの日付にする

- ステータス: 採用
- 日付: 2026-09-13

## コンテキスト

2006〜2007年ごろVoxに投稿していた記事が、旧ブログ経由で「On Vox: 」で始まるタイトルのまま21件残っていた（2006-11〜2007-09）。

- 冒頭1行と「» Voxで読む」リンクだけの抜粋が8件。うち3件は同じタイトルの全文記事が別にあり、残り5件は全文がどこにもない（Voxは2010年に終了。Wayback Machineに全文があるのは1件のみ）
- 全文が入っているものが13件。末尾に「Originally posted on qli.vox.com」がある。うち「アンフェア the movie」は接頭辞なしの記事と本文が完全に一致し、「パラダイム : レミオロメン」「グッバイ パスネット」は「On Vox:」記事どうしで2件ずつあった
- 「On Vox:」記事の日付は `Z` 付きだが、本文の内容（「公開初日初回8時50分…これから寝よう」、封切り日に「今日は…封切りされる日」）と合うのはJSTとして読んだ場合だった

## 決定

- 抜粋だけの記事は、全文記事の有無にかかわらずすべて削除する（Wayback Machineからの復元はしない）
- 同じ記事が重複している場合は、接頭辞なしの記事を残す。「On Vox:」記事どうしの重複は、変換残骸（`class=”enclosure …`）のない方を残す
- 残す「On Vox:」記事はタイトルから「On Vox: 」を外す。Voxからの転載であることは本文末尾の「Originally posted on qli.vox.com」で分かる
- 残す「On Vox:」記事の日付は時刻の数字をそのままJSTとみなし、`Z` を `+09:00` に置き換える

## 結果・影響

- 21件のうち11件を削除し、10件を接頭辞なし・`+09:00` の日付で残した。削除した抜粋記事にだけ付いていた作品名のタグ（`kiraware-matsuko`, `trick`）は、残した全文記事に `auto_tagger.rb --apply` で付け直した
- URLはUUIDのため、タイトル変更によるリンク切れはない。削除した記事はどの記事からもリンクされていなかった
- 日付に `+09:00` を持つのはこの10件だけで、他の記事は `Z` 付きか時差なし。Hugoは記事ごとの時差のまま表示するので、表示される日付は変更前と同じ
- 接頭辞なしで残した元記事側（例: 「幸福な食卓」200701/33f436e7）の日付は「On Vox:」版より7〜8時間遅れていたが、ずれているかどうか確証がないため変更していない
