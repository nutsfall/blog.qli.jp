# ADR-0019: 重複記事の自動削除スクリプトを廃止し、一覧を作って人が判断して消す

- ステータス: 採用
- 日付: 2026-09-13

## コンテキスト

`scripts/duplicate_post_cleaner.rb`（2025-09-15追加）は本文の類似度85%以上を重複とみなし、スコアで1件を選んで残りのページバンドルを削除するスクリプトだった。「On Vox:」記事の整理（ADR-0018）で、明らかな重複を1件も拾っていなかったことが分かった。

- `content/posts` の直下しか走査しないため、2025-12-13に `YYYYMM/UUID` 構成へ再編して以降は1件も読み込んでいなかった
- パスを直しても、本文を空白区切りの単語で比べるので日本語では類似度が出ない。URLや変換残骸も含めて比べる。本文が同じ記事どうしでも0.56〜0.65で、閾値に届かなかった
- 同じ整理の中で、本文・日付が完全に同じ記事（「myloが活気づいてきた！」200612）も見つかった

## 決定

- `duplicate_post_cleaner.rb` を削除する
- 重複の疑いがある記事は、その都度候補を抽出して一覧（本文の有無、対応記事、日付・タグの差）を作り、ユーザーが残す・消すを判断してから削除する

## 結果・影響

- 記事を自動で削除する経路がなくなる
- インポート時に重複を防ぐ仕組みは引き続きない（PLAN.md の既知の課題）

## 却下した代替案

- スクリプトを `YYYYMM/UUID` 構成と日本語に対応させて直す: 検出はできても削除まで自動で行う作りが、削除前に人が判断する運用と合わない。検出だけなら都度の抽出で足りる
- そのまま置いておく: 動かないうえに、使えるスクリプトとしてドキュメントに載り続ける
