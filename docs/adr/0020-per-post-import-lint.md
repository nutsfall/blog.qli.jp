# ADR-0020: インポート後処理の完了確認は content_lint.zsh の記事単位モードで行う

- ステータス: 採用
- 日付: 2026-11-08

## コンテキスト

新しいMedium記事の整形（`git pull`、`process_new_posts.rb`、タグ付け、画像の取り込み）をサブエージェントに任せることにした。任せた作業が終わったかを判定する手段が必要になった。

`scripts/content_lint.zsh` は全記事の件数を出すだけで、新しい記事だけの合否は分からない。重複タイトルの見出しやタグの付け忘れも検出できなかった。

## 決定

`content_lint.zsh` に `--post <記事ディレクトリ|index.md>...` のモードを追加する。記事ごとに次を確認し、問題があれば内容を出力して exit 1 で終わる。

- `draft: true` のまま／タグがない
- 本文先頭の見出しがタイトルと同じ（正規化は `process_new_posts.rb` と同じ: NFC、NBSPを空白に、大文字小文字を無視）
- リモート画像参照、Medium画像URL、計測ピクセル、空画像 `![]()` が残っている
- 本文・figure・cover が参照するローカル画像の実ファイルがない
- ページバンドル内の未参照ファイル、実体が画像でない画像ファイル

引数なしの従来モードの出力は変えない（ADR-0008 の前後比較に使っているため）。

## 結果・影響

- サブエージェントは整形の最後に `--post` を実行し、すべて OK になるまで直してからコミットする
- Mediumのタグが付いたまま再付与されていない場合は検出できない。Mediumのタグと区別する情報が記事に残らないため

## 却下した代替案

- 別のlintスクリプトを新しく作る: 画像の判定（マジックバイト検査など）が `content_lint.zsh` と重複する
- `process_new_posts.rb` に検証を組み込む: タグ付けはスクリプトの外（Claude Codeセッション）で行うので、スクリプトの終了時点では完了を判定できない
